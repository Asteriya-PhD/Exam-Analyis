# 需求规格说明书 — 校级联考质量分析系统

## 1. 项目背景

多校联合考试（简称联考）是高中阶段常见的教学评估方式。各校管理层和教师需要一份统一的、可视化的质量分析报告，用于横向对比各校上线情况、尖子生分布和学科贡献度。

## 2. 用户目标

| 角色 | 目标 |
|------|------|
| 教学管理者 | 横向对比各校上线人数/率、尖子生分布、学科贡献度，评估整体教学质量 |
| 年级主任 | 查看总分分布、批次上线情况，识别临界生分布 |
| 学科教师 | 查看所教学科在各校的均分对比、贡献率和命中率 |
| 学校领导 | 获取可导出的分析报告，用于汇报和存档 |

## 3. 功能需求

### F1: 数据导入与解析

- **F1.1** 支持上传 `.xlsx` / `.xls` 格式的 Excel 文件
- **F1.2** 自动检测学生记录中的列：学校、科类（物理/历史）、各科分数、总分
- **F1.3** 若「科类」列缺失，根据科目组合（含物理/历史科目）自动推断
- **F1.4** 加载演示数据功能（内置模拟数据集）

### F2: 学校与批次线配置

- **F2.1** 上传后显示所有学校列表，支持多选过滤
- **F2.2** 显示和编辑 4 条批次线：超一流、600分、双一流、一本线
- **F2.3** 每条批次线包含总分线 + 各科单科线
- **F2.4** 支持物理/历史科类分别配置批次线

### F3: 联考概览

- **F3.1** 参考学校总数与参考总人数
- **F3.2** 各科类（物理/历史）人数统计与均分
- **F3.3** 批次划线信息展示（总分线 + 单科线）
- **F3.4** 各校核心数据一览表（参考人数、总分均分、总分最高分）

### F4: 各校上线对比

- **F4.1** 按科类切换查看
- **F4.2** 各批次上线人数柱状图（学校为横轴，批次为系列）
- **F4.3** 各批次上线率折线图
- **F4.4** 各校上线数据明细表（人数 + 率值）

### F5: 尖子生排名

- **F5.1** 物理科类展示前 30 名，历史科类展示前 10 名
- **F5.2** 成绩明细表：排名、学校、各科分数、总分

### F6: 尖子生分层均分对比

- **F6.1** 支持前 30 / 100 / 200 名三个层级切换
- **F6.2** 语数外 + 总分双 Y 轴柱状图 + 散点图叠加
- **F6.3** 其他学科独立柱状对比图
- **F6.4** 跨层级（30→100→200）总分趋势图
- **F6.5** 各校均分明细表

### F7: 前 X% 均分对比

- **F7.1** 按科类展示前 X%（默认 30%）均分对比
- **F7.2** 核心科目 + 总分双 Y 轴图
- **F7.3** 其他学科柱状对比图
- **F7.4** 学校均分明细表

### F8: 优秀生分布

- **F8.1** 按前 10 / 20 / 50 / 100 / 200 名阈值展示分布
- **F8.2** 100% 堆积柱状图展示各校占比
- **F8.3** 人数和占比明细表

### F9: 学科贡献度

- **F9.1** 按科类 + 按学校切换查看
- **F9.2** 贡献率（双上线人数 / 总分上线人数）× 命中率（双上线人数 / 参考人数）气泡图
- **F9.3** 学科明细数据表：贡献率、命中率、双上线人数、参考人数、等级
- **F9.4** 等级划分：优秀(≥40%) / 良好(≥25%) / 一般(≥10%) / 较弱

### F10: 导出功能

- **F10.1** 将所有科类的所有图表和表格导出为 PNG 图片
- **F10.2** 图片打包为 ZIP 文件下载
- **F10.3** 导出内容覆盖全部 7 个分析板块

### F11: 科类切换

- **F11.1** 每个分析板块独立切换物理/历史科类
- **F11.2** 切换时销毁当前图表并重新渲染

## 4. 非功能需求

### N1: 性能

- **N1.1** 单次分析渲染时间 < 2s（5-6 校数据）
- **N1.2** 科类切换响应 < 500ms
- **N1.3** 导出操作 < 10s（完整 ZIP 包）

### N2: 兼容性

- **N2.1** 支持 Chrome / Edge / Safari 最新版本
- **N2.2** 无需后端服务，完全浏览器端运行
- **N2.3** 支持静态服务器部署或浏览器直接打开

### N3: 可维护性

- **N3.1** 单文件架构，便于分发和部署
- **N3.2** 模块化函数组织，每个渲染函数职责单一
- **N3.3** 图表实例管理（创建/销毁/重建）统一由 `destroyChart` / `destroyCharts` 管理

## 5. 数据规范

### 输入数据格式

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 学校 | 文本 | 是 | 学校名称 |
| 科类 | 文本 | 推荐 | 物理/历史（缺失则自动推断） |
| 各科分数 | 数字 | 是 | 各科目成绩列 |
| 总分 | 数字 | 是 | 总分列 |

### 输出指标

| 指标 | 说明 |
|------|------|
| 上线人数 | 达到某批次线的学生数 |
| 上线率 | 上线人数 / 参考人数 |
| 贡献率 | 某科双上线人数 / 总分上线人数 |
| 命中率 | 某科双上线人数 / 该科参考人数 |
| 均分 | 各组/各校的平均分 |
| 优秀生分布 | 前N名中各校的人数及占比 |
| 趋势 | 跨层级总分均分变化 |

## 6. 限制与边界

- 不处理综合科类汇总（仅物理/历史分别分析）
- 学校数限制为 5-6 校（颜色板可扩展至 9 色）
- 不包含小题分析
