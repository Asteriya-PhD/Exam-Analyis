# 校级联考质量分析系统

单文件 HTML 数据可视化工具（~3100 行），用于多校联考（5-6 校）成绩质量分析。上传学生成绩 Excel，自动生成 7 大分析板块 + 联考概览，支持 ZIP 包导出全部图表和表格。

## 核心功能

| 模块 | 说明 |
|------|------|
| **联考概览** | 参考学校/人数统计、各科类分布、批次划线信息、各校核心数据一览（人数/均分/最高分） |
| **各校上线对比** | 超一流/600分/双一流/一本线 各校上线人数（柱状图）+ 上线率（折线图） |
| **尖子生排名** | 物理前30名/历史前10名个人成绩明细表（学校+各科成绩+总分） |
| **尖子生分层均分对比** | 前30/100/200名各校语数外+总分双Y轴柱状散点图 + 其他学科柱状图 + 跨层趋势 |
| **前X%均分对比** | 核心科目+总分双Y轴图 + 其他学科柱状图，学校维度对比 |
| **优秀生分布** | 前10/20/50/100/200名各校人数占比 100% 堆积柱状图 + 明细表 |
| **学科贡献度** | 按学校的贡献率×命中率气泡图 + 分学科数据表（贡献率/命中率/双上线/等级） |

## 数据格式

每行一名学生，包含以下列：

| 列名 | 说明 |
|------|------|
| 学校 | 学校名称 |
| 科类 | 物理 / 历史（若缺失则根据科目组合自动推断） |
| 各科分数列 | 语数英 + 选科科目 |
| 总分 | 总分列 |

## 配置参数

- **批次线**：超一流 / 600 分 / 双一流 / 一本线（总分 + 各科单科线，可编辑）
- **学校选择**：上传后勾选需对比的学校
- **科类切换**：每个板块独立切换物理 / 历史
- **尖子生分层阈值**：前 30/100/200 名
- **前 X% 阈值**：30%（可配置）

## 技术栈

- [Chart.js 4.x](https://www.chartjs.org/) — 柱状图、折线图、散点图、气泡图、堆积图
- [SheetJS (xlsx)](https://sheetjs.com/) — Excel 解析
- [chartjs-plugin-datalabels](https://chartjs-plugin-datalabels.netlify.app/) — 图表数据标签
- [JSZip](https://stuk.github.io/jszip/) — 导出打包为 ZIP（图表截图 + 表格 Canvas 绘制）

## 使用

1. 打开 `exam-analysis.html`（可部署到任意静态服务器或用浏览器直接打开）
2. 上传 Excel 文件（支持 .xlsx / .xls）
3. 勾选需分析的学校，编辑批次线参数
4. 点击「生成分析」查看全部 7 个分析板块
5. 点击「导出图表」下载 ZIP 包（含全部科类所有图表和表格的 PNG 图片）
