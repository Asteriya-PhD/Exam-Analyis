# 校级联考质量分析系统

单文件 HTML 数据可视化工具，用于多校联考（5-6校）成绩质量分析。上传学生成绩 Excel，自动生成7大分析板块，支持 PDF 导出。

## 核心功能

| 模块 | 说明 |
|------|------|
| **联考概览** | 参考学校/人数统计、各科类分布、批次划线信息、各校核心数据一览 |
| **各校上线对比** | 超一流/600分/双一流/一本线 各校上线人数（柱状图）+ 上线率（折线图，tooltip悬停查看） |
| **尖子生排名** | 物理前30名/历史前10名个人成绩明细表（学校+各科成绩+总分） |
| **尖子生分层均分对比** | 前30/100/200名各校语数外+总分双Y轴柱状散点图 + 其他学科柱状图 + 跨层趋势 |
| **前30%均分对比** | 语数外+总分双Y轴图 + 其他学科柱状图，学校维度 |
| **优秀生分布** | 前10/20/50/100/200名各校人数百分比堆积柱状图 |
| **学科贡献度** | 按学校的贡献率×命中率气泡图 + 分学科数据表 + 贡献等级 |

## 数据格式

每行一名学生，包含以下列：

| 列名 | 说明 |
|------|------|
| 学校 | 学校名称 |
| 科类 | 物理 / 历史 |
| 各科分数列 | 语数英 + 选科科目 |
| 总分 | 总分列 |

支持自动检测：若数据中无「科类」列，则根据科目名称（物理/历史科目组合）推断。

## 配置参数

- **批次线**：超一流/600分/双一流/一本线的总分和各科单科线
- **学校数**：5-6校配置
- **尖子生分层**：前30/100/200名 + 前30%（可自定义）
- **赋分/原始分**：支持原始分和赋分数据

## 技术栈

- [Chart.js 4.x](https://www.chartjs.org/) — 柱状图、折线图、气泡图
- [SheetJS (xlsx)](https://sheetjs.com/) — Excel 解析
- [chartjs-plugin-datalabels](https://chartjs-plugin-datalabels.netlify.app/) — 数据标签
- [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) — PDF 导出

## 使用

1. 打开 `exam-analysis.html`（可部署到任意静态服务器或用浏览器直接打开）
2. 上传 Excel 文件
3. 配置学校选择和批次线参数
4. 点击「生成分析」查看结果
5. 点击「导出 PDF」下载报表

## 配色方案

- 主色：深色 `#141413` / 浅色 `#faf9f5`
- 强调色：橙色 `#d97757` / 蓝色 `#6a9bcc` / 绿色 `#788c5d`
